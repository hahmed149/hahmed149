# hahmed.dev

Hamza Ahmed's résumé as a drivable road trip, built with three.js and Vite.
Every course and accomplishment is an obstacle on the highway.

- `npm run dev` starts a local server.
- `npm run deploy` builds and publishes to the `gh-pages` branch (served at https://hahmed.dev).
- Content lives in `src/data.js`. Link to a stop with `https://hahmed.dev/#cerner` (any section id).
